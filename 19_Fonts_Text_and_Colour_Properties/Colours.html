Lets Learn About Colour Properties

Colours are represented in these ways:-

  1. Color Keywords-red,yellow,cyan etc
  2. Hex Colour Code- #ff000,#00ff00 etc
  3. RGB-rgb(Red,Green,Blue)- eg-rgb(52,48,36)
  4. RGBA-rgb(Red,Green,Blue,Alpha)-eg-rgb(58,89,42,0.5)
  5. HSL-hsl(Hue,Saturation,Lightness)-eg-hsl(4,5,3)

These Values are used to get customized colour.Except "Colour keywords"

To genrate Colour codes go to - https://htmlcolorcodes.com/

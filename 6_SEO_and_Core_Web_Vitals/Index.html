What is SEO?

SEO means optimizing a website so it can rank better in search engines like Google.

What is CORE WEB VITALS?

Core Web Vitals are performance and user-experience metrics used to measure how well a webpage works for visitors.

Main Core Web Vitals

LCP=How Quickly The Main Content Appears.According to Google The Large page of our website should load in 2.5 sec...

FID=It measured how long a website took to start responding when a user first interacted with it, such as clicking a button or link.It should process in 100ms

INP=How quickly the website responds to clicks/taps.It Should process in 200ms

CLS=Whether elements unexpectedly move around.It should process in 0.1ms

WHAT IS LIGHT HOUSE REPORT?

Lighthouse Report is an automated website audit report that checks the quality and performance of a webpage. It is built into Chrome DevTools.It includes-Performance,Accessiblity,Seo,Best Practices
